# Sunny Park: ABC, Colors & Shapes 🎡🎈🦆

Детская обучающая PWA-игра для iPad (возраст ~2 года) без сборщиков и внешних зависимостей: чистый HTML/CSS/JS, локальный шрифт Fredoka (`woff2`), векторные иллюстрации, предзаписанная английская озвучка и полная офлайн-работа.

## 5 аттракционов в парке
1. **🎈 BALLOONS (Шарики)** — 3 режима: **9 цветов** (*Red, Orange, Yellow, Green, Blue, Purple, Pink, White, Brown*), буквы **A–Z** и цифры **1–10** с финальным поздравлением после полного набора.
2. **🦒 A B C (Карточки-перевёртыши)** — крупные 3D-карточки `A–Z`: по нажатию переворачиваются и показывают иллюстрацию и английское слово (*Alligator, Bear, Cat, Dog, Elephant, Frog, Giraffe, Horse, Iguana, Jellyfish, Koala, Lion, Monkey, Narwhal, Owl, Pig, Quail, Rabbit, Sheep, Tiger, Unicorn, Violin, Whale, X-ray fish, Yak, Zebra*).
3. **🦆 DUCKS (Уточки по цветам)** — плавающие цветные уточки в бассейне и цветные домики снизу (поддержка и перетаскивания, и нажатия, с «кря» и озвучкой цвета).
4. **🚂 SHAPES (Фигуры)** — 8 живых фигур (*Circle, Heart, Square, Triangle, Star, Diamond, Oval, Rectangle*) на красном парковом поезде и качающемся кораблике.
5. **🎨 DRAW A–Z (Обводилка букв)** — плавная обводка букв `A–Z` пальцем в Safari с тактильным звуком рисования и скрываемой панелью выбора букв (`A–Z`).

> Выход в парк из любой игры — **удержанием кнопки «Домой» (~0.6 с)** с заполняющимся кольцом, чтобы малыш не выходил случайным касанием. При каждом повторном заходе любая игра начинается заново.

## Как проверить локально
```bash
cd "/Users/shamil/Library/Mobile Documents/com~apple~CloudDocs/1 Projects/Side Projects/abc-colors"
python3 -m http.server 8123 --bind 127.0.0.1
```
Откройте `http://127.0.0.1:8123` в браузере (рекомендуемые вьюпорты iPad: `1180×820` landscape и `820×1180` portrait).

## Как установить на Главный экран iPad (GitHub Pages)
1. Опубликуйте папку в GitHub Pages (сейчас: `https://shamil-gdev.github.io/abc-colors/`).
2. Откройте ссылку на iPad **в Safari** → **Поделиться** → **На экран «Домой»** → **Добавить**.
3. После первого запуска с интернетом Service Worker (`sw.js`, кэш `sunny-park-abc-v5`) сохранит все скрипты, локальный шрифт Fredoka и аудиофайлы — дальше игра работает полностью **офлайн**.
