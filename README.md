# Sunny Park: ABC & Colors 🎡🎈🦒

Детская обучающая PWA-игра для iPad (возраст ~2 года): английский алфавит **A–Z** и **10 цветов** в формате парка аттракционов с живой предзаписанной озвучкой и полной офлайн-работой.

## Аттракционы внутри парка
1. **🦒 A B C (Карточки и кубики алфавита)** — крупная цветная сцена с прыгающей буквой, персонажем/предметом и кубиками `A–Z`. Нажатие на букву произносит букву, на картинку — слово, на кубик — связку *«A! Apple!»*.
2. **🎈 COLORS (Шарики и мыльные пузыри)** — плавающие цветные шарики (`🎈`) и пузыри (`🫧`) с поддержкой мультитача и увеличенной зоной попадания для детской ручки + баночки с красками снизу, запускающие шарики выбранного цвета.
3. **✨ PAINT A–Z (Волшебная раскраска букв)** — гигантская буква на фиолетовом фоне с пунктирной дорожкой и зелёным бегущим кружком (можно как вести пальчиком, так и просто нажимать по дорожке, меняя цвет краски сверху).

## Как быстро проверить на iPad по домашнему Wi‑Fi
1. На Mac в папке проекта запустите сервер:
   ```bash
   cd "/Users/shamil/Library/Mobile Documents/com~apple~CloudDocs/1 Projects/Side Projects/abc-colors"
   python3 -m http.server 8123 --bind 0.0.0.0
   ```
2. Узнайте локальный IP вашего Mac (`ipconfig getifaddr en0`, например `192.168.1.25`).
3. Откройте на iPad в **Safari** адрес `http://<IP-вашего-Mac>:8123`.

## Как установить на Главный экран iPad (полноэкранный режим + офлайн)
Для полноценной работы офлайн (Service Worker в iOS требует HTTPS) залейте папку `abc-colors` на любой бесплатный статический хостинг:
- **Cloudflare Pages / Netlify Drop** — просто перетащите папку `abc-colors` в браузер.
- **GitHub Pages** — загрузите файлы в репозиторий и включите Pages.

Затем на iPad в **Safari**:
1. Откройте ссылку на игру.
2. Нажмите кнопку **Поделиться** (`квадрат со стрелкой вверх`).
3. Выберите **«На экран „Домой“» (Add to Home Screen)** → **Добавить**.
4. На рабочем столе iPad появится яркая иконка **ABC Park** — игра открывается на весь экран без адресной строки Safari и работает даже без интернета!
